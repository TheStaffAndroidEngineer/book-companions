# The Staff Android Engineer — code companions

Start with [Common Goods](https://github.com/TheStaffAndroidEngineer/commerce-app), the integrated shopping application. Other repositories are independently runnable chapter checkpoints and labs. Use each repository’s minimal README for build prerequisites and local service commands.

Only companion code, build files, required assets, tests, licence notices and setup/index metadata are hosted here. Chapter prose, written exercises/solutions and editorial evidence remain in the paid book and author workspace. Reference and learner implementations in source code remain available.

All repositories are private. No new companion-code licence is granted by this upload. Chapter 32 is prose-only and has no code repository.
